# PassForge 🔐

Enterprise-grade password security intelligence platform implementing:

- Shannon entropy analysis
- Brute-force attack modeling
- HIBP breach simulation
- NIST SP 800-63B compliance
- OWASP ASVS alignment
- MITRE ATT&CK T1110 mapping

---

## Features

- Real-time password strength analysis
- Entropy and keyspace calculations
- Dictionary and pattern detection
- Keyboard walk detection
- Secure password generator
- Threat modeling dashboard
- Cryptographically secure randomness
- Client-side privacy-first architecture
